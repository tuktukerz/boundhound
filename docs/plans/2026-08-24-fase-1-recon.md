# Phase 1 — Recon: Implementation Plan

> REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use `- [ ]`.

**Goal:** Add the first real recon tools (subfinder/httpx/nmap) reachable only through the `bh-exec` choke point, plus a `recon-map` synthesizer, a self-authored `pentest-recon` skill, and a REAL e2e — without weakening any Phase 0 guarantee or breaking existing tests.

**Spec:** `docs/specs/2026-08-24-fase-1-recon-design.md`

## Global Constraints
- No new enforcement bypass. The two command-building extensions MUST be backward-compatible: every existing test stays green, and the anti-smuggling invariant holds (a target reaches a tool only via scope-checked `--target`; an `extraArgs` value is consumed only right after a declared `takes_value` flag and must match a `value_pattern` that cannot express a host).
- Runtime = Node ESM `.mjs`; tests = `bun test`; no build step.
- English for all repo artifacts (this phase also cleans residual Indonesian in files it touches).
- Tools run ONLY in-container via `docker exec bh-<engagement>`, never on host.
- Deny-by-default / fail-closed / `out_of_scope` wins — unchanged.
