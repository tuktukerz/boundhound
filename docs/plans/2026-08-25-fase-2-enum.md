- Anti-smuggling preserved: a target reaches a tool only via the scope-checked `--target`; value flags carry paths/numbers/enums that cannot express a host.
- Runtime Node ESM `.mjs`; tests `bun test`; no build step. English only. Tools run only in-container.
- Deny-by-default / fail-closed / audit — unchanged.
