**Spec:** `docs/specs/2026-08-24-fase-0.5-plugin-packaging-design.md`

## Global Constraints
- No new attack capability; enforcement LOGIC unchanged (only code-vs-data location changes).
- All existing tests must stay green (regression gate).
- Runtime = Node ESM `.mjs`, tests = `bun test`, no build step.
- English for all repo artifacts.
